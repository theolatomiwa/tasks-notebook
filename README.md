# Tasks Notebook

A calm, notebook-style to-do app: steps under tasks, people you work for, due dates, a focus timer and a little buddy called Ember.

Everything lives in one file, `index.html`. Open it in a browser, or deploy the folder as a static site (e.g. Vercel). Tasks are saved in each browser's local storage, so use **Back up / Restore** in the sidebar to move them between devices.
